Applies an observation-based finite-state controller to a POMDP and constructs the induced DTMC.

States of the resulting DTMC represent reachable pairs of a POMDP state and an FSC memory node. If the FSC provides observation signatures or action names, they are used to match its outputs to the POMDP; otherwise, the corresponding numeric IDs are assumed to agree. Observation signatures match observable names and typed values, so the observable-storage order need not agree. State-action rewards are averaged over the FSC action distribution and added to state rewards. Models containing transition rewards are not supported.

Template Parameters
PomdpValueTypeThe type used for probabilities and rewards in the POMDP and resulting DTMC.
FscValueTypeThe type used for probabilities in randomised FSC action outputs.
Parameters
pomdpThe canonic POMDP to which the controller is applied.
fscThe finite-state controller to apply.
treatUnspecifiedChoiceAsDontCareIf true, an unspecified FSC output selects local action zero and keeps the current FSC memory node. If false, an unspecified output causes an exception.
Returns
The DTMC induced by the POMDP and the FSC.
Exceptions
storm::exceptions::IllegalArgumentExceptionIf the POMDP is not canonic.
storm::exceptions::NotSupportedExceptionIf the POMDP does not have exactly one initial state or any reward model has transition rewards.
storm::exceptions::UnexpectedExceptionIf required observation or action names cannot be matched, or if the FSC has an unspecified output and treatUnspecifiedChoiceAsDontCare is false.

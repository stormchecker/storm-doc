Creates a POMDP (with state-based observations) out of an MDP and a transition-based observation function.

Parameters
mdpThe input MDP. If this is actually a POMDP, its observation function will be ignored.
transitionObservationFunctionAn observation function mapping transitions to observations O : S x Act x S -> Z
initialObservationThe observation used for the initial state(s) of the POMDP
dropUnreachableStatesRemove states unreachable from the initial states (default: true). In this mode, the observation callback is only invoked for nonzero transitions from reachable states, using original state IDs and local action indices.
Returns
A POMDP with state-based observations that is equivalent to the input MDP with the given observation function. Specifically, the observation assigned to the state is equal to the transition-observation with which the state has been entered. This might require to create copies of states that can be entered with different observations. Initial states retain initialObservation. If unreachable states are retained, non-initial states without incoming transitions retain one copy with initialObservation. This fallback can produce incompatible action counts within the initial observation class.

Makes rewards observable by extending observations with the state and state-action reward values of the selected models.

The input POMDP must have exactly one initial state and no transition rewards in the selected reward models.

Parameters

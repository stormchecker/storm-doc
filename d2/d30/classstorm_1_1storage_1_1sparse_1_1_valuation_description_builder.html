Detailed Description

Helper to incrementally build a ValuationClassDescription, i.e.

the description of a class of valuations as specified by the UMB (Unified Markov Binary) format. The resulting ValuationClassDescription must stay compliant with the UMB specification.

See also
https://pmc-tools.github.io/umb/spec
https://arxiv.org/abs/2606.17811

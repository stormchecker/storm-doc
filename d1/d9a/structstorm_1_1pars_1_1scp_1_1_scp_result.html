Detailed Description

template<typename ConstantType>
struct storm::pars::scp::ScpResult< ConstantType >

The outcome of an SCP search at ConstantType precision (double or storm::RationalNumber): the best point found (valuation and value, see FeasibilityResult), together with how the search ended.

Only for status == Feasible has valuation been verified by model-checking the instantiated model at ConstantType precision; for the other statuses it is a best-effort point.

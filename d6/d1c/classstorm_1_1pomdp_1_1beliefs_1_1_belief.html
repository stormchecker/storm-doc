Detailed Description

template<typename ValueTypeArg>
class storm::pomdp::beliefs::Belief< ValueTypeArg >

Represents a belief of a Pomdp, i.e.

a probability distribution over the states of a POMDP. A belief also knows its observation.

Note
A belief cannot be modified or assigned after construction. Use the BeliefBuilder class to construct new beliefs. Moving a belief transfers its contents and leaves the source in a moved-from state.
Template Parameters
ValueTypeArgthe type of the values (probabilities) of the belief.

Calls the function f for each state in X with the arguments (state, value1, value2), where.

  • value1 is the value for state of this belief
  • value2 is the value for state of the other belief
  • if considerOnlyThisSupport is true, X is the set of states in the support of this belief
  • otherwise, X is the set of states in the support of either this or the other belief

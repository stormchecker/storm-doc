◆ build()

template<typename BeliefType>
BeliefType storm::pomdp::beliefs::BeliefBuilder< BeliefType >::build ( )

Builds the belief and returns it.

Precondition
the belief must be a valid probability distribution, i.e., all values are in [0,1] and sum up to 1. Furthermore, an observation must have been set before calling this.
Note
After calling this, the builder is in an invalid state. Before building another belief with this builder, the reset() method must be called.

◆ normalize()

template<typename BeliefType>
BeliefBuilder< BeliefType >::ValueType storm::pomdp::beliefs::BeliefBuilder< BeliefType >::normalize ( )

Normalizes the belief, i.e., if the sum of the values is not 1, it divides all values by the sum.

Hence, after calling this, the sum of the values is 1.

Precondition
the sum is must be strictly greater than 0.
Returns
the sum of the values (before normalization)

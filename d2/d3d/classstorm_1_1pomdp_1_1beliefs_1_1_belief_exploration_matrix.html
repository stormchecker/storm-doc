Detailed Description

template<typename ValueType, typename... ExtraTransitionData>
class storm::pomdp::beliefs::BeliefExplorationMatrix< ValueType, ExtraTransitionData >

Sparse transition data for the explored part of a belief MDP.

Rows correspond to actions and row groups to explored beliefs. Extra transition data is stored alongside each probability, for example reward-bound updates or clipping corrections.

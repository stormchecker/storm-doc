◆ NumericPrecisionFactor

double storm::pomdp::beliefs::detail::NumericPrecisionFactor = 1e14
constexpr

Used to decide whether two belief values are equal.

Two values x,y are equal if round(x * NumericPrecisionFactor) == round(y * NumericPrecisionFactor), where the factor is 1e14. Thus, a high value means that we are more precise. This is only relevant if beliefs are represented using an inexact data type like double

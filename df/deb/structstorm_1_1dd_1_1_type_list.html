Detailed Description

template<typename... Types>
struct storm::dd::TypeList< Types >

Static description of a DD backend: which optional capabilities it offers and for which value types its Internal{Bdd,Add,DdManager} specializations are actually functional.

A new backend adds one specialization here and implements the contract in BackendConcepts.h.

"Supports a value type" means that the backend's InternalAdd<..., ValueType> works, not merely that it is explicitly instantiated (CUDD, for example, is instantiated for RationalNumber, but most operations throw). A list of types, used to enumerate the value types of a backend.

Detailed Description

Computes a hash of an expression such that syntactically equal expressions hash to the same value.

This is the hash counterpart of SyntacticalEqualityCheckVisitor: for any two expressions that satisfy isSyntacticallyEqual, this visitor returns the same hash. The converse does not hold, so a hash can be used to speed up the lookup of syntactically equal expressions, but a hash equality alone does not establish syntactic equality.

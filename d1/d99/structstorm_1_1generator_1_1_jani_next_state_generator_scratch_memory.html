Detailed Description

template<typename ValueType, typename StateType>
struct storm::generator::JaniNextStateGeneratorScratchMemory< ValueType, StateType >

The actual (private) implementation of JaniNextStateGeneratorScratchMemory, see the corresponding member in JaniNextStateGenerator.h.

Scratch memory used internally by JaniNextStateGenerator.

This is a friend of JaniNextStateGenerator<ValueType, StateType> so that it can reuse its (private) EdgeSetWithIndices/AutomataEdgeSets typedefs.

Its definition lives in the .cpp file (pimpl idiom) so that this (rather public) header does not expose these implementation details and does not need to be recompiled whenever they change.

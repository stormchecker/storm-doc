Detailed Description

template<typename PomdpModelType, typename BeliefValueType, typename BeliefMdpValueType, typename PolicyValueType = BeliefMdpValueType>
class storm::pomdp::policy::PolicyExtractor< PomdpModelType, BeliefValueType, BeliefMdpValueType, PolicyValueType >

Extracts concrete policy representations from a scheduler for a belief MDP.

The extractor can construct an observation-based finite-state controller for the original POMDP or the Markov chain induced by the belief-MDP scheduler. Approximation schedulers, if provided, determine the behavior at truncated belief states. With clipping, FSC export is approximate; see exportPolicyAsFiniteStateController().

ObservationBasedFiniteStateController< PolicyValueType > storm::pomdp::policy::PolicyExtractor< PomdpModelType, BeliefValueType, BeliefMdpValueType, PolicyValueType >::exportPolicyAsFiniteStateController ( ) const

Constructs an observation-based finite-state controller from the belief-MDP scheduler.

Available observation valuations and choice labels are included as matching metadata when they provide suitable mappings. Observation valuations are exported as typed signatures, so they can be matched against an equivalent POMDP with a different observable-storage order. Approximation schedulers are currently supported only for memoryless policies and encoded as self-looping controller nodes for truncated belief states. Supporting finite-memory cut-off policies requires controller nodes for the scheduler memory states and transitions implementing their memory updates.

Clipping is only approximated: probability mass redirected to target or bottom states has no continuation policy. No continuation is reconstructed for this mass, so the FSC may leave actions unspecified for the corresponding outcomes in the original POMDP. Its value on the original POMDP may therefore differ from the reported belief MDP value.

Returns
The extracted finite-state controller.
Exceptions
storm::exceptions::IllegalArgumentExceptionif a used approximation scheduler assigns different action distributions to states sharing an observation within the same scheduler memory state.

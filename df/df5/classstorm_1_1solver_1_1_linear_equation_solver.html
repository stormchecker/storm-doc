◆ solveEquations()

template<typename ValueType>
bool storm::solver::LinearEquationSolver< ValueType >::solveEquations ( Environment const & env,
std::vector< ValueType > & x,
std::vector< ValueType > const & b ) const

If the solver expects the equation system format, it solves Ax = b.

If it it expects a fixed point format, it solves Ax + b = x. In both versions, the matrix A is required to be square and the problem is required to have a unique solution. The solution will be written to the vector x. Note that the matrix A has to be given upon construction time of the solver object.

Parameters
xThe solution vector that has to be computed. Its length must be equal to the number of rows of A.
bThe vector b. Its length must be equal to the number of rows of A.
Returns
true

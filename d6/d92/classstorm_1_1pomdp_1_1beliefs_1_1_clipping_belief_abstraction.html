Detailed Description

template<typename BeliefType>
class storm::pomdp::beliefs::ClippingBeliefAbstraction< BeliefType >

Approximates a belief by clipping it to an observation-specific grid point.

See also
10.1007/978-3-030-99527-0_2

Clipping preserves the probability mass represented by the grid belief and reports the removed mass separately to the callback. For expected rewards, optional extremal state values yield the reward correction for removed mass.

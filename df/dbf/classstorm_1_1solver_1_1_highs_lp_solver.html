Detailed Description

template<typename ValueType, bool RawMode = false>
class storm::solver::HighsLpSolver< ValueType, RawMode >

A class that implements the LpSolver interface using HiGHS.

Note that HiGHS only supports variables and values of type double. In particular, no support for exact arithmetic (storm::RationalNumber) is provided. For exact computations, choose a different solver, e.g., Z3.

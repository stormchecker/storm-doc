Detailed Description

template<typename BeliefMdpValueType, typename PomdpType, typename BeliefType>
class storm::pomdp::beliefs::BeliefExploration< BeliefMdpValueType, PomdpType, BeliefType >

Class to perform belief exploration.

Heavily templated to allow for different belief, value, abstraction, etc. types. Therefore, implementations are in the header file.

Template Parameters
BeliefMdpValueTypeValue type used in the constructed belief MDP.
PomdpTypePOMDP type used for successor generation.
BeliefTypeSparse belief representation.

VectorValueType storm::modelchecker::detail::multiplyRowWithVectorAddNumber ( storm::storage::SparseMatrix< ValueType > const & matrix,

ValueType const & offset )

Computes the (possibly infinite) value offset + sum_{j} P(rowIndex, j) * vector[j] for the given row.

The result is infinite if there is a successor with positive probability whose value is infinite. This works no matter whether the value type has an infinity of its own (e.g. double) or whether it is extended by one (e.g. rational numbers, see storm/utility/ExtendedNumber.h).

Template Parameters
VectorValueTypeEither ValueType or the type that extends ValueType with infinity

template<typename ValueType, typename ElementType>
storm::json< ValueType > storm::modelchecker::detail::valuesToJson ( std::vector< ElementType > const & values)

Converts the given values to a json array.

Infinite values are written as the strings "inf" and "-inf". Values of an exact type (i.e., rational numbers) are written as strings of the form "numerator/denominator" since json numbers cannot represent them.

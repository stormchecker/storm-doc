Detailed Description

Stores valuations of variables for a set of entities (e.g.

states / observations) in the packed, bit-level binary layout defined by the UMB (Unified Markov Binary) format. The in-memory layout of this class must therefore stay compliant with the UMB specification so that the raw data obtained via getRawUmbData() can be written to / read from a UMB file without further conversion.

See also
https://pmc-tools.github.io/umb/spec
https://arxiv.org/abs/2606.17811

Detailed Description

template<typename ValueType>
class storm::storage::BackwardTransitionCache< ValueType >

This class caches the backward transitions of a given forward transition matrix.

The backward transitions are computed (using SparseMatrix::transpose) the first time they are requested. They have a trivial row grouping, i.e., there is one row for each state. By default, forward transitions with value zero are dropped, i.e., the backward transitions only contain entries for non-zero forward transitions (see parameter keepZeros of the constructors). The forward transition matrix reference needs to remain valid throughout the lifetime of this cache. The cache can be copied and moved (but not assigned), and the actual backward transitions are shared. This means that if the matrix is computed (or cleared) in one of the copies, this is also the case for all other copies.

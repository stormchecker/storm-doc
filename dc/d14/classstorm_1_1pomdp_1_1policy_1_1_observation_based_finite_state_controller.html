Detailed Description

template<typename ValueType>
class storm::pomdp::policy::ObservationBasedFiniteStateController< ValueType >

A finite-state controller (FSC) for POMDPs that bases its decisions on observations.

Each node in the FSC corresponds to a memory state. For every node-observation pair for which the FSC defines an output, it specifies an action to take and the successor node to transition to. An FSC is generally partial: outputs need not be defined for every observation in every memory node. As the controller does not itself store the observation universe, it cannot determine whether it is complete for a particular POMDP. Use hasOutputForObservationInNode() to check a node-observation pair before retrieving its output. Observation and action IDs do not need to be continuously numbered, e.g. if the FSC stems from a belief MDP where some observations and actions are not used. Action IDs correspond to local action indices for the respective observation. Optional observation signatures and action-name mappings allow the controller to be applied to POMDPs whose numeric IDs differ.

Writes a JSON representation of the controller.

The root object contains initial-node, deterministic, and nodes. Each node contains its id and transitions; only defined outputs are represented as transitions. Each transition records an observation, successor, and an actions array whose entries contain an action id and probability. Available observation signatures are included as signature fields, and action names as name fields.

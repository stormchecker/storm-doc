◆ establishGraphPreservation()

template<typename ValueType>
storm::pars::analysis::GraphPreservationStatus storm::pars::establishGraphPreservation ( std::shared_ptr< storm::models::ModelBase > const & model,
std::vector< storm::storage::ParameterRegion< ValueType > > const & regions,
bool graphPreservationRequired )

Determines to what extent the regions are known to be well-defined and graph-preserving.

Graph preservation implies well-definedness. If graph preservation is assumed, we only warn about regions that are provably not graph-preserving (or not well-formed). Otherwise, if graphPreservationRequired is set, a proof is required and an exception is raised if there is none. If it is not set (e.g. for robust parameter lifting, which handles non-graph-preserving regions itself), only well-definedness is determined.

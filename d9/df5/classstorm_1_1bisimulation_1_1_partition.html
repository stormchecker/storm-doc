Detailed Description

Represents a partition of a set of consecutive indices.

Allows efficient access to the blocks of the partition and the elements in each block. Memory is cache-friendly and linear in the number of elements (independent of block count). The downside is that merging blocks is not supported.

bool storm::bisimulation::Partition::splitBlockByClustering ( Block const & block,
Condition const & condition )

Splits the given block by anchor-based clustering: repeatedly picks the first not-yet-grouped element as the anchor of a new group, moves every remaining not-yet-grouped element e with !condition(anchor, e) into that group (wherever it currently sits in the block), and finalizes the group once no more such elements remain; then continues with the next not-yet-grouped element as the next anchor.

Unlike splitBlockByOrder, this does not require condition to be consistent with any (total or weak) order over the block's elements.

Parameters
conditionreturns true for pairs of elements that should not be in the same block; only ever invoked with the (still not-yet-grouped) anchor of the group currently being built as the first argument.
Returns
true iff the block was split, i.e. if the input block is now a proper super block.

Splits the given block according to the given order and splitting condition.

Specifically, the elements in the block are first sorted according to the given order resulting in a (sorted) block [e_0, e_1, e_2, ..., e_m]. Then, indices i_0, i_1, ..., i_k are determined such that

  • i_0 = 0 and
  • i_j > i_{j-1} is the smallest number such that condition(e_i_{j-1}, e_{i_j}) is true (or i_j = m+1 if no such number exists). We then split the block into subblocks [e_i_{j-1}, ..., e_{i_j-1}]
    Parameters
    lessmust define a strict weak order (required for well-defined sorting)
    splitConditionreturns true for elements that should not be in the same block as explained above
    Returns
    true iff the block was split, i.e. if the input block is now a proper super block.

Splits the given block according to the given predicate.

Specifically, the elements in the block are swapped around, such that all elements where the predicate f evaluates to false come first. Then, two sub-blocks are created accordingly. If all elements are true/false, no splitting is performed.

Returns
a pair containing first the 'false' sub-block and then the 'true' sub-block. One of them can be empty.

Splits the given block according to the given range of elements.

Specifically, the elements in the block are swapped around, such that all elements that are not in the given range come first. Then, two sub-blocks are created accordingly. If the range is empty or contains all elements of the block, no splitting is performed.

Parameters
rthe input range.
Returns
a pair containing first the sub-block that is not in the range and then the sub-block in the range. One of them can be empty.
